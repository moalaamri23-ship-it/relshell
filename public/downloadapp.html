Install from the browser menu

  1. In Microsoft Edge, click Settings and more (…) at the top right.
  2. Choose Apps → Install this site as an app.
  3. Click Install.

In Chrome: ⋮ → Cast, save and share → Install page as app…

Already installed? Edge shows Open in app in the address bar, or find RelShell in the Start menu.
